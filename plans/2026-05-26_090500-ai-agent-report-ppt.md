# 方案：中国AI Agent发展报告 → 杂志风PPT

**目标**：从 3.2 万字的《全球AI Agent技术演进及中国体制内应用落地调查报告》中提取结构化精华内容，用 guizang-ppt-skill 生成一份可用于线下分享/私享会的网页 PPT。

---

## 前置假设

| 项目 | 假设 | 确认方式 |
|------|------|----------|
| 受众 | 行业内部 / 政策研究 / 体制内信息化负责人 | Step 1 澄清 |
| 时长 | 20-30 分钟 | 约 15-20 页 |
| 风格 | 报告偏政策+数据+案例，**A · 电子杂志风**更合适（人文+行业观察定位） | Step 1 确认 |
| 配图 | 无现成图片，需 AI 生成或占位色块 | Step 1 确认 |
| 交付物 | 单文件 HTML，本地可打开 | 固定 |

---

## Phase 1 · 内容提取与结构化

### 1.1 分层提取策略

用并行子任务对报告做三层提取：

| 层 | 任务 | 产出 |
|----|------|------|
| **核心论点层** | 从 7 章中各提取 1-2 条核心论述 | 10-15 条金句级论点 |
| **数据层** | 提取全部可量化数据（市场规模、增长率、百分比） | 数据卡片池 |
| **案例层** | 提取 4 个标杆案例的关键要素（痛点 → 方案 → 效果） | 案例摘要卡 |

### 1.2 提炼方法

使用 `delegate_task` 启动 3 个并行 leaf subagent，各司其职：
- Subagent A：提取核心论点（技术演进 + 政策 + 趋势）
- Subagent B：提取结构化数据（市场、时间表、配额）
- Subagent C：提取案例摘要（政务热线、安徽法务、政策大脑、智慧招投标）

### 1.3 输出格式

合并后输出一份 **PPT 内容大纲**，每页标注：
- 页号 / 主题 / 推荐 Layout / 关键内容 / 数据点 / 情绪节奏

## Phase 2 · PPT 生成（guizang-ppt-skill）

### 2.1 风格选择

报告特征：政策文件、市场规模数据、体制内案例、技术趋势 → **Style A · 电子杂志风**

理由：
- 衬线标题适合"调查报告"的权威感
- 图片网格适合展示 4 个案例截图/配图
- 数据大字报（Layout 3）适合市场规模翻倍数据
- 两列流水线（Layout 6）适合 Agent 闭环流程

### 2.2 页数规划（草案，15-18 页）

### 2.3 执行步骤

按 guizang-ppt-skill 工作流：

1. **Step 1 · 需求澄清** — 向用户确认受众、时长、风格、配图、硬约束（7 问清单中的关键项）
2. **Step 2 · 拷贝模板** — `cp assets/template.html → 项目目录/index.html`，选主题色（推荐 #1 墨水经典或 #2 靛蓝瓷）
3. **Step 3 · 填充内容** — 按 3.0 预检 → 3.0.5 主题节奏 → 3.1 挑布局 → 3.2 图片比例，逐页填充
4. **Step 4 · 对照 checklist 自检** — P0 项全部通过
5. **Step 5 · 本地预览** — 浏览器打开验证
6. **Step 6 · 迭代** — 根据反馈调整

### 2.4 配图策略

无现成图片，两个方案：
- **方案 A**：先用占位色块生成完整结构，后期补图
- **方案 B**：在 Codex 中用 GPT-M 2.0 生成配图（需 codex 环境）

## Phase 3 · 验证

- 翻页流畅性（键盘/滚轮/触屏）
- 全部图片不撑破、不堆底
- 字体分工正确（衬线标题 + 非衬线正文 + 等宽元数据）
- 中文大标题 ≤ 5 字且 nowrap
- 无 emoji，全 Lucide 图标

## 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 用户未确认风格/受众就开工 | PPT 方向错误，全盘重做 | Phase 2 Step 1 必须拿到确认 |
| 报告案例缺少视觉素材 | Layout 4/5/10 图文页空洞 | 先用占位色块，或跳过纯图页 |
| 中文长标题换行挤成竖排 | 排版灾难 | Layout 选择时严格控制每页标题 ≤ 6 字 |
| 动效系统 Motion One 离线加载失败 | 翻页动画消失但内容可读 | template 已内置 CDN + 本地双保险 |
