# Dify 变压器自动填报系统 — 方案案例

> 2026-05-11 方案规划案例，用于参考 Dify 多模态工作流的设计模式。

## 场景概述

用户需要基于 Dify 工作流，输入变压器名称，自动从电力单线图中识别「变电站 + 10kV线路 + 杆塔号 + 变压器名称」完整路径，联网查询相关资料，完成自动填报。

## 关键设计决策

### 1. 多模态识别节点

- **模型**：Qwen2.5-VL-72B（SiliconFlow API）
- **原因**：中文电力术语理解好，API 稳定，支持 OpenAI 兼容接口
- **提示词要点**：
  - 要求严格 JSON 输出，不要其他文字
  - 定义设备类型枚举（substation|line|pole|transformer|breaker|isolator）
  - 包含 bbox 坐标便于后续验证
  - 定义连接关系语义（connected|feeds|branches）

### 2. Code 节点路径回溯

- **Dify Code 节点使用 `inputs` 而非 `args` 接收上游输出**（重要修正）
- BFS 向上回溯构建层级路径
- 需处理边界：未找到变压器、环检测、多路径

### 3. 联网检索

- **方案 A**：调用电力行业公开 API（推荐）
- **方案 B**：Dify 内置搜索引擎 + LLM 提取（兜底）
- 需做名称归一化（"XX变" vs "XX变电站"）

### 4. 置信度与人工审核

- 置信度 < 0.8 的字段强制加入"需人工确认"列表
- 在 End 节点前添加人工审核标记
- 支持用户手动修正后重新提交

## 主要风险

1. **单线图识别精度（高）**：电力符号高度专业化，通用 VLM 识别率约 60-70%
   - 应对：few-shot 示例 + 人工审核兜底 + 置信度阈值
2. **变电站名称模糊匹配（中）**："XX变"与"XX变电站"可能匹配不到同一实体
   - 应对：名称归一化（去掉"变"/"变电站"后缀统一匹配）
3. **Dify Code 节点超时（低）**：复杂回溯算法可能超时
   - 应对：控制在 500 行以内
