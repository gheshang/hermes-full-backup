# 分段审查最佳实践

## 分段命名约定

用户可能用不同方式指代分段：

| 用户说法 | 对应内容 | 处理方式 |
|----------|----------|----------|
| "分段1" | 第一幕/第一部分/开篇 | 搜索"分段"关键词，若无则按"第一幕"定位 |
| "开篇钩子" | 文章开头300-500字 | 定位到文档开头，提取前300-500字 |
| "朋友故事引入" | 第一个配角出场段落 | 搜索"朋友""配角"关键词，定位到对应段落 |
| "第X幕" | 按幕次编号 | 搜索"## 第X幕"或"## X."标题 |
| "重审" | 对已审核过的分段再次审核 | 先找审核报告，对比上轮问题 |

## 分段边界确认清单

审核前必须确认：

- [ ] 分段起止位置（行号范围）
- [ ] 分段内容摘要（用一句话描述该分段讲什么）
- [ ] 该分段在全文中的功能（开篇/发展/高潮/结尾）
- [ ] 是否有上轮审核报告（重审时）

**示例确认话术**：
> "分段1是指第一幕（L1-L52），开篇钩子+朋友故事引入部分，对吗？"

## 常见分段类型检查清单

### 开篇钩子分段

| 检查项 | 评估标准 |
|--------|----------|
| 情绪钩子 | 是否立刻建立基调（如"膝盖会响但不想"） |
| 悬念钩子 | 是否有未解决的问题悬在头顶 |
| 视觉钩子 | 是否有可感知的视觉意象 |
| 数字钩子 | 是否有量化元素（存款、时间、距离等） |
| 人物引入 | 主角是否立刻登场，性格是否鲜明 |
| 环境铺垫 | 环境描写是否传递氛围 |

### 朋友/配角引入分段

| 检查项 | 评估标准 |
|--------|----------|
| 功能明确 | 配角是否承担明确功能（信息传递者/对比者/引导者） |
| 对话自然 | 对话是否口语化，有潜台词 |
| 人物区分 | 配角与主角的性格/说话方式是否有区分 |
| 伏笔埋下 | 配角的身份/关系是否埋下后续伏笔 |
| 伏笔回收 | 伏笔是否在后续回收（全局关联检查） |

### 高潮/转折分段

| 检查项 | 评估标准 |
|--------|----------|
| 张力峰值 | 是否达到该段落的张力峰值 |
| 因果完整 | 转折是否有充分铺垫 |
| 人物反应 | 人物反应是否符合性格 |
| 节奏控制 | 节奏是否匹配张力（紧张时短句，舒缓时长句） |

### 结尾分段

| 检查项 | 评估标准 |
|--------|----------|
| 收束完整 | 主要线索是否有收束（不必全部闭合） |
| 余味 | 是否留给读者思考空间 |
| 呼应 | 是否与开篇形成呼应 |
| 不煽情 | 是否避免过度情感渲染 |

## 重审注意事项

1. **不要简单重复**：重审不是把同样的问题再说一遍，而是带着上轮报告再审核
2. **追踪修改效果**：上轮建议修改的问题，本轮是否已修复？修复效果如何？
3. **发现遗漏问题**：本轮是否发现了上轮遗漏的问题？
4. **发现新问题**：上轮建议的修改是否引入了新问题？
5. **对比维度必填**：重审报告必须包含"与上轮审核对比"表格

## 文件命名约定（建议）

如果文章有多个分段文件，建议命名约定：

```
文章名.md              # 完整文本
文章名-分段1.md        # 第一幕/开篇
文章名-分段2.md        # 第二幕/发展
文章名-审核报告.md     # 审核报告
文章名-审核报告-v2.md  # 重审报告
```

如果用户指定"分段1"但找不到独立文件，应：
1. 定位到完整文本
2. 按章节/幕次切分
3. 明确告知用户："未找到独立分段文件，已按第一幕（L1-L52）提取内容审核"
