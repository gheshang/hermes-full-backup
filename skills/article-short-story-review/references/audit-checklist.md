# 审核检查清单

## 文章审核检查清单

### 逻辑一致性
- [ ] 情节连贯：前文伏笔有呼应，后文无未解矛盾
- [ ] 人物行为：角色动机前后一致，无突兀转变
- [ ] 时间线：事件顺序合理，无时间悖论
- [ ] 因果链：每个结果有合理前因

### 事实与常理
- [ ] 硬事实：历史事件、科学原理、数据准确
- [ ] 常理判断：人物反应符合人类行为常识
- [ ] 专业领域：医疗/法律/金融内容已核实或标注"虚构"

### 句子级质量
- [ ] 语法正确：无主谓不一致、成分残缺、搭配不当
- [ ] 语义清晰：无指代不明、歧义、过度修饰
- [ ] 无冗余：无同一意思反复表达、无效填充词
- [ ] 节奏合理：无长句堆砌或短句碎片化

### 叙事质量
- [ ] 开篇有吸引力：首段建立悬念/冲突/情感钩子
- [ ] 节奏把控：高潮铺垫充分，结尾收束有力
- [ ] 情感共鸣：读者能与角色产生情感连接
- [ ] 主题表达：核心思想清晰，非说教式灌输

## 短片文案检查清单

### 声画匹配
- [ ] 文案与画面/镜头语言同步
- [ ] 声画不同步 < 3次且累计 < 3秒
- [ ] 画面被字幕/贴纸遮挡 < 30%

### 信息价值
- [ ] 专业度：持续正向输出，让用户获得增益
- [ ] 可读性：语言通俗，专业词汇有解释
- [ ] 场景化：描述了适用场景（季节/场合/人群/使用方式）

### 情绪钩子（开头3秒）
- [ ] 运用了以下至少一种：恐惧/嫉妒/愤怒/懒惰/贪婪
- [ ] 抛出了结论/悬念/冲突

### 口播质量
- [ ] 语速/音量适中
- [ ] 介绍有条理
- [ ] 情绪积极/稳定
- [ ] 字数与时长匹配（中文约3-4字/秒，偏差<20%）

### 合规底线
- [ ] 无违法违规内容（低俗色情、不良价值观）
- [ ] 无版权侵犯（未授权肖像/音乐/品牌标识）
- [ ] AI生成内容已添加显式+隐式标识

## 10轮编辑审查流程

| 轮次 | 专注维度 | 核心检查项 |
|------|----------|------------|
| 1 | 故事核 | 冲突是否明确？主角目标是否清晰？ |
| 2 | 结构 | 开头是否包含人物+场景？结尾是否收束？ |
| 3 | 人物一致性 | 角色决策是否驱动情节？语言是否个性化？ |
| 4 | 人物弧光 | 至少一个角色是否因事件发生改变？ |
| 5 | 因果链 | 每个结果是否有合理前因？有无机械降神？ |
| 6 | 展示vs讲述 | 是否"show where appropriate, tell where appropriate"？ |
| 7 | 节奏 | 高潮铺垫是否充分？有无冗长段落？ |
| 8 | 语言精炼 | 删除所有"very"等弱副词；删冗余重复 |
| 9 | 朗读测试 | 出声朗读，检查拗口句、节奏断裂 |
| 10 | 情感共鸣 | 读者能否与角色产生情感连接？ |
