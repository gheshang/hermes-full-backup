## 短片文案附加审查

### 声画匹配
- [ ] 文案与画面/镜头语言同步
- [ ] 声画不同步 < 3次且累计 < 3秒
- [ ] 画面遮挡 < 30%

### 信息价值
- [ ] 专业度：持续正向输出
- [ ] 可读性：语言通俗，专业词有解释
- [ ] 场景化：描述了适用场景

### 情绪钩子（开头3秒）
- [ ] 运用了以下至少一种：恐惧/嫉妒/愤怒/懒惰/贪婪

### 口播质量
- [ ] 语速/音量适中
- [ ] 介绍有条理
- [ ] 情绪积极/稳定
- [ ] 字数与时长匹配（3-4字/秒，偏差<20%）

### 短片附加分
| 项 | 条件 | 得分 |
|----|------|------|
| 爆款潜力 | 开头有强情绪钩子+信息价值高 | +___/5 |
| 传播性 | 有金句/可截图内容 | +___/3 |
| 视觉创意 | 文案与画面高度创新 | +___/3 |
| 口播拗口 | 朗读测试发现拗口 | -___/5 |
| 信息过载 | 单位时间信息量过大 | -___/5 |

**短片总分 = 基础分 + 附加分 = ___/110**
