# 文章/短片小说审核技能

## 审核维度（6项）

1. **逻辑一致性**：情节连贯、人物行为一致、时间线合理、因果链完整
2. **事实与常理**：硬事实准确（上网验证）、人物反应符合常识、专业内容需核实
3. **句子级质量**：语法错误、语义模糊、冗余重复、节奏问题
4. **叙事质量**：开篇有钩子、高潮铺垫充分、情感共鸣、主题清晰
5. **短片特有**：视觉匹配、时长适配（3-4字/秒）、口播流畅、信息密度
6. **AI味检测**：模板化连接词、中庸和稀泥、空洞修饰、通用例子、情感缺失、重复啰嗦、套路开头结尾

> 详细AI味检测标准见 `references/ai-trace-detection.md`

## 审核流程

### 前置步骤：文档定位与确认（必须执行）

1. **定位文档**：根据用户提供的标题/关键词/路径搜索目标文档
2. **确认存在**：找到文档后，确认内容与用户描述一致（标题、章节号、主题关键词）
3. **无法找到时的处理**：
   - 列出已搜索的路径和关键词
   - 列出相似文档（如文件名包含部分关键词）
   - 询问用户：文档来源（飞书/本地路径/其他）或提供文档内容
   - **不要猜测**：宁可确认也不盲审

### 正式审核

```
通读建立印象 → 分层扫描（结构→逻辑→事实→语言→叙事→AI味）→ 问题分类(P0-P3) → 输出报告
```

### 长文本分段审查（>2000字必须启用）

当文本超过2000字时，**必须**用subagent分段审查，避免上下文遗忘：

1. **分段**：按语义段落切分，每段500-800字
2. **并行审查**：每段一个subagent，独立审核该段
3. **全局交叉**：主agent汇总各段结果，重点检查：
   - 段间逻辑衔接是否断裂
   - 人物/事件/时间线跨段是否一致
   - 事实核查跨段是否有矛盾
4. **合并报告**：汇总所有问题，按P0-P3统一排序

> **注意**：分段审查不能替代全局审查。段内问题由subagent发现，段间问题由主agent发现。
> 
> **分段指定审查/重审流程**：详见 `references/segment-review-best-practices.md`。

---

### 分段指定审查（用户指定"分段X"或"第X幕"）

当用户明确指定审核某个分段（如"分段1"、"开篇钩子部分"、"第一幕"）时：

1. **文档定位**：
   - 搜索文件名包含"分段"、"第X幕"、"第一部分"等关键词的文件
   - 若无独立分段文件，则定位到完整文本，按章节/幕次切分
   - **不要猜测**：如果找不到对应分段文件，列出已搜索路径并询问用户文档来源

2. **分段边界确认**：
   - 明确该分段的起止位置（从第X行到第Y行，或从"第X幕"到"第Y幕"）
   - 如果用户未明确边界，主动确认："分段1是指第一幕（L1-L52）吗？"

3. **重审/复审处理**：
   - 如果用户说"重审"，先搜索是否有该文章的"审核报告"文件
   - 读取上轮审核报告，对比本轮发现的问题
   - 在报告中明确标注"与上轮对比"维度，说明本次是补充评估还是发现新问题

4. **分段审查输出**：
   - 使用标准审核报告模板
   - 在报告头部明确标注审查范围（如"审查范围：第一幕（L1-L52），开篇钩子+朋友故事引入部分"）
   - 如果该分段是全文的一部分，在"与上轮对比"或"全局关联"中说明该分段与后续内容的伏笔/回收关系

---

### 重审/复审流程

当用户要求"重审"时：

1. **搜索上轮审核报告**：查找同名的"-审核报告.md"或类似文件
2. **读取上轮报告**：了解上轮发现的问题、修改建议、评分
3. **对比本轮发现**：
   - 上轮已发现的问题本轮是否依然存在？
   - 本轮是否发现了上轮遗漏的问题？
   - 本轮是否发现上轮建议修改后引入的新问题？
4. **输出对比维度**：在报告末尾添加"与上轮审核对比"表格，明确标注变化

> **注意**：重审不是简单重复审核，而是"带着上轮报告再审核一次"，重点追踪修改效果和遗漏问题。

**P0致命**：逻辑断裂/事实错误 → 必须改
**P1严重**：影响阅读体验 → 建议改
**P2建议**：可优化 → 可选改
**P3微调**：个人偏好 → 随意

## 评分体系（百分制）

| 维度 | 满分 | 评分标准 |
|------|------|----------|
| 逻辑一致性 | 20 | 18-20完美；14-17少量跳跃；10-13明显矛盾；<10断裂 |
| 语言质量 | 20 | 18-20精准有风格；14-17通顺有瑕疵；10-13多处语病；<10难读 |
| 信息价值 | 20 | 18-20高密度可信；14-17充足一般；10-13不足；<10空洞 |
| 叙事/结构 | 20 | 18-20精妙有层次；14-17完整；10-13松散；<10无结构 |
| 情感/共鸣 | 20 | 18-20强烈共鸣；14-17有感染力；10-13平淡；<10无感 |
| **AI味（扣分）** | **-20~0** | 见下方扣分表 |

**等级**：A(85-100)可直接发布 / B(70-84)改P1后发布 / C(60-69)改P0+P1重审 / D(<60)重写

### AI味扣分表（20分起扣）

| 特征 | 扣分 | 判定标准 |
|------|------|----------|
| 模板化连接词 | -2~-5 | "首先/其次/最后/总之"≥3次 |
| 中庸和稀泥 | -3~-5 | "一方面...另一方面"无立场 |
| 空洞修饰语 | -2~-4 | "令人印象深刻/具有重要意义"≥3次 |
| 通用例子 | -2~-4 | 例子无具体细节，可套任何文章 |
| 情感缺失 | -2~-5 | 全文无个人语气，像机器人念稿 |
| 重复啰嗦 | -2~-4 | 同一意思重复≥2次 |
| 套路开头结尾 | -2~-3 | "在...日益重要的今天""希望本文..." |

**AI味得分 = 20 - 扣分总和**（最低0）

### 短片附加分（±10）

加分：爆款潜力(+3~5)、传播金句(+2~3)、视觉创意(+2~3) | 扣分：口播拗口(-2~-5)、信息过载(-2~-5)

## 优秀标准速查

| 指标 | 优秀 | 不合格 |
|------|------|--------|
| 逻辑自洽 | 伏笔有呼应，因果完整 | 核心矛盾 |
| 信息密度 | 每段有新信息 | 大量重复空话 |
| 语言精准 | 用词准确，句式有变化 | 大量语病歧义 |
| 情感/思想 | 有独特观点，引发共鸣 | 无观点纯堆砌 |
| 结构完整 | 开头有钩子，结尾有收束 | 开头冗长结尾仓促 |
| 去AI味 | 有个人语气，无模板痕迹 | AI味浓重像机器人生成 |
| 3秒留存（短片） | 开头有情绪钩子或强结论 | 开头平淡无重点 |
| 口播流畅（短片） | 朗读顺口，语速适中 | 大量拗口语速失控 |

## 事实核查流程（必须执行）

1. **识别**：标记所有涉及历史/科学/数据/法律/专业术语的语句
2. **搜索**：web_search验证，记录来源
3. **分类**：✓正确 / ✗错误+正确信息+链接 / ?待核实
4. **报告**：单独列出"事实核查结果"

> **警告**：AI会产生幻觉，不能依赖模型判断事实，必须独立验证。

## 11轮审查法（小说/故事专用）

1.故事核 2.结构 3.人物一致性 4.人物弧光 5.因果链 6.展示vs讲述 7.节奏 8.语言精炼 9.朗读测试 10.情感共鸣 11.AI味检测

## 常见陷阱

| 陷阱 | 规避 |
|------|------|
| 只找错不肯定 | 强制输出"亮点" |
| 过度主观 | 区分"事实错误"和"风格偏好" |
| 只审核不给方案 | 每个问题附修改建议+参考版本 |
| AI幻觉误判 | 事实类必须上网验证 |
| 长文本遗忘 | 分段审核后全局交叉比对 |
| 忽略文体差异 | 先判断文体再套用对应检查清单 |
| **概念附加错误条件** | 理论概念解释时，不要添加削弱理论本身的附加条件（如"过剩人口"附加"没有存款"） |
| **跨场景逻辑断裂** | 分段审查后必须检查段间/场景间的逻辑连贯性（如场景8"预算不变"→场景9"砍预算"） |
| **夸张失实表述** | 警惕"比X还多"等绝对化夸张，需核实或改为相对表述 |
| **句子结构复杂拗口** | 长句需朗读测试，主从句切换时检查主语是否一致 |
| **绝对化断言** | "所有人都没有存款"类表述需改为"很多人"或"大部分人" |
| **文档未找到即盲审** | 用户指定特定分段/章节时，必须先确认文档存在且内容匹配，搜索不到时应列出已搜索路径并询问来源，不可凭空推测内容 |
| **分段边界未确认** | 用户指定"分段X"时，必须明确起止行号和内容摘要，不可假设边界 |
| **重审未对比上轮** | 用户要求"重审"时，必须搜索并读取上轮审核报告，在报告中添加"与上轮对比"维度 |
| **忽略伏笔回收** | 分段审查时，必须检查该分段埋下的伏笔是否在后续回收（全局关联检查） |

## 修改意见原则

1. 每个问题必须有**原文引用**
2. 每个问题必须有**修改建议**
3. 修改建议必须有**参考版本**（具体可替换文字）
4. 区分"必须改"(P0)和"建议改"(P1)
5. 重大修改后**重新审核**
