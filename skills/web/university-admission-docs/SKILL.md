# 高校招生简章下载流程

## 适用场景
- 用户要求下载某高校的博士/硕士招生简章
- 需要获取完整的招生政策、报考条件、专业目录等信息

## 核心发现：招生简章是分层结构

高校招生简章**不是单个文件**，而是分散在3-4个层级：

| 层级 | 内容 | 位置 |
|------|------|------|
| 学校总章程 | 报名时间、选拔方式、学费、录取规则 | 研招网 yz.xxx.edu.cn |
| 学院/学部实施细则 | 具体报考条件、英语要求、成果要求、成绩计算 | 学部官网 |
| 专业目录 | 招生人数、研究方向、导师名单 | PDF/DOCX附件 |
| 专项计划通知 | 协同提质计划等补充 | 研招网通知公告栏 |

**必须三层都抓，缺一不可。**

## 操作步骤

### 1. 定位官网入口
```
web_search: "{学校名} {年份} {博士/硕士} 招生简章 site:xxx.edu.cn"
```
优先找研招网 `yz.xxx.edu.cn`，不要用第三方网站（内容不全/有误）。

### 2. 抓取学校总章程
- 用 `web_extract` 抓研招网招生简章页面
- **注意**：内容超过5000字会被截断，需要：
  - 抓多次（offset不同）或
  - 抓第三方转载站（高顿、考博猫等）获取完整文本，再与官网交叉验证
  - 官网原文URL必须保留在最终文档中

### 3. 找学院/学部实施细则
```
web_search: "{学校名}{学部名} {年份} {专业} 申请考核制 招生实施细则"
```
- 实施细则通常在学部官网，不在研招网
- 有时以 DOCX/PDF 附件形式提供 → 下载后提取文本

### 4. 下载附件（专业目录等）
```bash
curl -fL -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36" \
  -o /tmp/filename.pdf "PDF_URL"
```
- **必须加 `-fL`**：`-f` 失败时报错（否则curl静默下载HTML错误页），`-L` 跟随重定向
- **必须加 User-Agent**：部分服务器拒绝无UA的请求

### 5. 提取附件内容
- PDF：用 `pymupdf`（`fitz`）库的 `page.get_text()` 提取
- DOCX：用 `python-docx` 库的 `Document(filepath).paragraphs` 提取
- 安装命令用 `pip3`（uv管理的Python环境需要用pip3而非pip）

### 6. 整合保存
将三层信息整合为一个Markdown文件，包含：
- 学校总章程要点
- 学部实施细则全文
- 专业目录表格化
- 官方链接
- 关键信息速览（供用户快速浏览）

文件保存到 `~/downloads/` 目录。

## 坑点与对策

| 坑 | 症状 | 对策 |
|----|------|------|
| 浏览器被拦 | `ERR_BLOCKED_BY_CLIENT` | 换 web_extract / curl |
| web_extract 截断 | 内容超5000字被截 | 抓第三方转载站补全；或分段抓取 |
| 知乎等平台403 | web_extract和scrapling都失败 | 放弃该源，找其他转载站 |
| curl下载为空 | 不加-fL时静默失败 | 必须加 `-fL -A "UA"` |
| pip装不上python-docx | uv环境下pip指向错误 | 用 `pip3` 安装 |
| 只有年份旧的简章 | 新版可能还没发 | 先提供最近年份，提醒用户关注官网更新 |

## 官网页面结构规律

大多数高校研招网（基于同一CMS模板）的结构：
- 博士招生简章列表页：`/12738/list.htm` 类似路径
- 单篇简章页：`/2025/0112/c12738a308611/page.htm` 日期+编号格式
- 附件URL：`/_upload/article/files/xx/xx/...` 格式
