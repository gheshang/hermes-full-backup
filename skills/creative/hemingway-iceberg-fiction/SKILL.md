# 海明威冰山写法重写流程

## 核心原则
1. **不信任读者=写废话，信任读者=留白**——凡是读者能自己推出的，删掉
2. **八分之七在水下**——写出来的只是露出水面的部分，水下的是删掉但结构仍支撑的东西
3. **字数砍50%+是常态**——不是减信息，是提密度

## 七刀实操清单

### 刀1：砍心理直述
- 删所有"她意识到/发现/知道/觉得/想起/明白"
- 替代方案：用身体反应（手抖/字变重/合上书）或沉默替代
- 检验：删掉后读者是否仍能推出同结论？能→删

### 刀2：砍叙述者论说
- 后记/结尾的哲理总结 → 替换为一个画面（一个动作、一个物件、一个未完成的姿态）
- 第四章式理论推演（"资本要增值→压缩成本→分层标价"）→ 删整段，只留人物行为

### 刀3：比喻系统只留一个
- 多个比喻系统（河流/算盘/机器/笼子）→ 选最能贯穿全文的一个，其余砍
- 留下的比喻也不加标注（"锁形""中间态"）→ 让读者自己看

### 刀4：对话碎片化
- 哲学长段 → 拆成碎片+身体动作穿插
- 辩论式多句反驳 → 一个质问即停
- 关键信息用反问抛出，不给答案

### 刀5：未完成句
- 破折号后面不跟解码句（"你说得——"永远不接"对，资本不是人"）
- 潜台词用日常话表达（"吃饭了吗"=我知道你受伤了但我不会说）

### 刀6：学术术语驱逐
- "资本的人格化""异化""剩余价值"→ 全文不出现
- 由人物对话/处境让读者自己推出概念

### 刀7：结尾画面化
- 最后一段必须是一个具体的、可感知的画面
- 不许有"看见是拆掉的前提"式的总结
- 发卡/铁锈/缝线——物件本身说话

## 验证标准
- [ ] 全文"意识到/发现/知道/觉得"出现0次
- [ ] 没有任何学术术语
- [ ] 结尾是画面不是论说
- [ ] 比喻系统≤1个
- [ ] 破折号/未完成句≥2处
- [ ] 字数比前一版少40%以上
