# 知识漫画配套小说写作与审核

## 适用场景

1. 知识漫画（baoyu-comic）产出分镜脚本后，用户要求配套短篇小说。
2. **理论文章→小说**：用户提供政论/哲学/理论文章（如马克思主义文献、毛泽东著作解读、社科论文），要求转化为有冲突、有弧线的文艺小说。
3. 任何"把抽象论理变成人物经历"的写作需求。

## 核心原则

**论点不是故事。** 把论点变成人物经历——让角色在误判中被碾压、在自我欺骗崩塌后重新站起来，论点才能活。

## 写作流程

### Step 1：加载两个框架

1. **叙事学家框架** — 读取 `~/agency-agents-zh/academic/academic-narratologist.md`
   - 提取：麦基核心理念、埃格里前提、沃格勒人物弧线、巴特五符码、契诃夫之枪追踪
2. **思想框架** — 根据主题选择
   - 马克思主义主题 → `mao-zedong-perspective` skill（矛盾分析、持久战略、统一战线）
   - 其他主题 → 从 `~/agency-agents-zh/` 角色库匹配相关角色

### Step 2a：从理论文章提取叙事骨架（理论文章入口专用）

当输入是理论文章（非分镜脚本）时，无法从storyboard提取，需要从论点直接转化：

**转化规则**：
- 每个核心论点 → 一个**人物处境**（不是人物台词，是人物所处的现实）
- 论证链条 → **人物弧线的转变轨迹**（论点的先后顺序=角色认知的层层深入）
- 文章中的"敌人/对立面" → 具体角色（但必须赋予对立角色主体性，不能写成纸片反派）
- 文章的解决方案/方向 → 结尾的**悬置**（绝不能变成角色的胜利宣言）

**符号提取**：理论文章中的核心概念→物件符号：
- "依附/财产"→锁、笼、快递单上的姓
- "量化剥削"→数字/账本/工资条
- "团结"→一通电话/一句没说完的话（不是集会演讲）
- 符号必须**物理化**——读者能摸到的东西，不是概念本身

### Step 2：从分镜脚本提取叙事骨架

从 `storyboard.md` 提取：
- 符号映射表（视觉符号→叙事承诺）
- 每页 Core Message（→章节主题）
- 色调演进（→情绪曲线参考）

但**不照搬分镜**——小说有自己的节奏，分镜是画面节奏，小说是心理节奏。

### Step 2b：论点→叙事处境全覆盖映射（Step 2a之后必做）

v1失败的根因：跳过此步骤，凭读后感直接写，导致大量论点遗漏。

**操作流程**：
1. 从理论文章逐条提取所有核心论点（上篇+下篇分别编号），通常15-30条
2. 对每个论点标注对应的**叙事处境**（哪一幕、哪个角色的什么遭遇来体现）
3. 全部映射后做覆盖审计：✅已映射 / ⚠️浅映射（只提到未展开） / ❌遗漏
4. ❌遗漏的论点必须补映射——要么并入已有处境，要么新增角色/场景

**映射规则**：
- 一个叙事处境可以承载多个论点（如"妈的三万二"同时承载"家主制→资本制承接"和"家务劳动无酬"）
- 一个论点必须有至少一个叙事处境（不能只在叙述者点评中出现）
- 论证链条的先后顺序 = 角色认知的递进顺序（上篇论点在前期幕，下篇论点在后期幕）

**输出格式**：
```
论点清单（编号 | 论点 | 映射处境 | 覆盖状态）
总计N条：✅ X | ⚠️ Y | ❌ Z
```

**不通过标准**：❌ > 0 时不允许进入Step 3。

### Step 2c：论点密度评估与分部决策（Step 2b之后必做）

Step 2b完成后，检查论点总数和叙事处境的承载比：

**评估标准**：
- 论点 ≤ 10条：单篇可承载，直接进Step 3
- 论点 11-16条：**高危区间**——理论文章转小说最常见的密度。单篇硬塞会导致每幕堆叠3-4个论点，节奏崩塌。必须考虑分部
- 论点 > 16条：几乎必定需要分部

**分部决策规则**：
1. 在Step 2b的覆盖审计中，如果⚠️（浅映射）超过1/3，说明单篇无法给每个论点足够的叙事空间→分部
2. 论点自然分为两个论证阶段（如"上篇=诊断，下篇=方案"）→按论证阶段分部
3. v1已写且用户认可→v1作为第一部分，第二部分从v1终点接续，补入剩余论点

**分部写作要求**：
- 每部分必须有独立的叙事弧线（不是上篇=铺垫+下篇=高潮，而是两部分各有完整的起承转合）
- 第一部分的结尾必须是第二部分的起跑线（如"要算的不只是我一个人的账"既是第一部分的认知落点，又是第二部分"算所有人的账"的起点）
- 两部分共享符号系统，但第二部分对第一部分的符号做**深化/变形/反转**（如"九百块"从v1的"不公平"→第二部分的"分化机制"）
- 第二部分新增的角色必须与第一部分形成呼应（如老张呼应李刚、方姐反衬阿兰）
- **绝对不能**把两部分写成同一篇的两个版本——第二部分是续写，不是重写

**反面教材**：v2试图把16条论点全塞进单篇，结果每幕变成论点清单，节奏崩塌，用户评价"不怎么样"。拆为v1(第一部分：笼+去依附条件)+第二部分(更大的笼+阶级分析+错误方向+团结)后，每幕只需推进1-2个论点，叙事空间充裕。

### Step 3：设计人物弧线（动笔前必做）

对每个主要角色填写：

```
人物弧线：[角色名]
弧线类型：[转变型/坚守型/扁平型/悲剧型]
欲望 vs 需求：[外在目标 vs 内在必需]
自我欺骗：[角色赖以运作的错误信念]
催化事件 → 中点转折（虚假胜利/虚假失败）→ 至暗时刻 → 转变
```

**关键检查**：
- 至暗时刻必须是**内在崩塌**（认知/信念被击碎），不能只是外在打击
- 自我欺骗必须在故事前半段明确建立，中段被角色身边最亲近的人戳破
- 转变不等于胜利——"看清了但路还长"比"觉醒即自由"更诚实

### Step 4：写作

**结构模型**：五幕式（铺陈→上升→中点→至暗→悬置解决）

**必须包含的冲突层次**：
1. **人际冲突**：角色之间的直接对抗（如老周拍桌子）
2. **认知冲突**：自我欺骗被戳破（如阿玲反驳小织）
3. **结构冲突**：系统性力量碾压个人（如裁员、降薪）
4. **内在冲突**：想退回旧认知的诱惑（如差点说"好"回到妈的笼子）

**四层缺一不可**。只写1-2层的就是v1——太平。

**节奏规则**：
- 中点之后必须有**反向压力**——虚假胜利迅速暴露为无效
- 至暗时刻之后不能立即给暖色——必须有一个"冷缓冲区"
- 结尾用"悬置"不用"解决"——这个题材下给出胜利是虚假的，给出绝望是犬儒的

**写作时的Tell词自检**（边写边查，不要留到审核）：
- 动笔每个认知转折段落时，搜"意识到/发现/明白/理解"——这些词在理论文章转小说时出现概率是正常创作的3-5倍
- 替换公式：`她意识到X` → 写让读者自己推出X的事实序列（数字、动作、物件排列）
- 例：`她忽然意识到八万开不了铺` → `八万。租金、设备、原料——算下来十五万。她攒了四年才四万。`
- 关键：**认知转折用事实冲击，不用心理标注**

### Step 5：符号回收审计

动笔前列出所有符号承诺（发卡、红绳、书、数字等），写完后逐项检查回收状态。

| 符号 | 首次出现 | 承诺 | 回收方式 | 状态 |
- 全部 ✅ → 通过
- 有 ⚠️ → 补一笔或故意留白（留白需有叙事目的）

## 审核流程

### 审核维度与输出格式

0. **论点覆盖审计**（理论文章入口专用，分镜脚本入口跳过）：重新从原文提取论点清单，逐条对照小说正文，标注覆盖状态。v1→v2升级的核心驱动力就是这个审计——叙事学再完美，论点缺一半也是失败。

1. **核心理念/前提**：故事真正表达的是什么？是论点还是弧线？
2. **结构拆解**：五幕式+张力曲线图（ASCII），标注峰值和低谷
3. **人物弧线**：每个角色的欲望/需求/自我欺骗/转变检查点
4. **叙事承诺追踪**：契诃夫之枪——所有符号是否回收
5. **巴特五符码**：阐释符码、行动符码、语义符码、象征符码、文化符码
6. **结构问题**：中点是否有效？至暗是否够深？主角后半段是否偏被动？
7. **具体改进建议**：指出章节位置+改什么+为什么改
8. **评分**（10分制）+ 一句话结论

### 审核时重点抓的问题

- **"被动承受"陷阱**：主角在中点之后如果只剩被动承受（裁员、降薪等），缺主动行动（哪怕失败），会让"坚持"变成精神状态而非实践
- **"觉醒即自由"套路**：角色看清真相后立刻脱胎换骨是假的——看清之后的反复碾压才是真的
- **敌人一元化**：如果全篇只有一个层次的敌人（男人/老板/结构），说明矛盾分析的深度不够
- **听众角色**：如果某角色只是主角的附和者/听众，要么升级为镜子（戳破自我欺骗的人），要么砍掉
- **符号一次性变形**：发卡/锁链等符号不应该一次性完成变形——渐变（锁→中间态→影子像钥匙）比突变更诚实

## 冰山写法改造流程

当用户要求"太直白""不够含蓄""意味深长""像海明威"时，按以下流程改造已有稿件。

### 核心原则

**作者不信任读者**是冰山改造的根本诊断——每一次理论转述、每一句心理直述、每一处比喻解释，都是作者在说"我怕你没懂"。改造方向：**信任读者**。

### 五刀法（按优先级排序）

1. **砍论说**：标出所有"作者借角色之口说教"的段落。判断标准——如果把这段删掉，读者能否从前后场景自己推出同样的结论？能→砍。不能→改为身体反应或动作。
   - 重灾区通常是"读理论书"场景和"后记/结尾声明"
   - 理论段改造公式：`长段论述 → 1-2个身体反应（手发抖/手指停顿/合上书）+ 1句刺入式短句`
   - 后记改造公式：`主题声明 → 一个画面（物件传承/光线变化/未完成动作）`

2. **砍Tell**：全局搜索"意识到/发现/知道/觉得/想起/明白/理解"。每个命中按以下规则替换：
   - `她意识到X` → 写一个让读者自己看出X的行为
   - `她觉得冷` → 保留（感官），但砍紧接的"不是A，不是B，是C"式拆解解释
   - `她想起Y` → Y作为独立短段闪回出现，不加"她想起"
   - `她知道Z` → 留行为后果，删认知过程

3. **砍重复**：数比喻系统。同一个道理用≥2个比喻说了，选一主一辅，砍其余。
   - 主比喻需能闭合符号线（如"笼子"闭合"锁→钥匙"）
   - 辅比喻只出现2次：1次解释主比喻的盲区，1次结尾呼应
   - 叙述者层面的比喻解释全部砍掉——比喻说了就是说了，不解释

4. **加潜台词**：审查每段对话——角色说的是否就是想的？如果是，加缝隙。
   - `阿玲冷静分析` → `阿玲只说一个词"便宜。"然后沉默`
   - `妈说苦命` → `妈说完苦命后加"吃饭了吗？"——话题急转弯=潜台词`
   - `老周"你说得对但我不想承认"` → `老周"你说得——"（破折号，永远未完成）`
   - 核心操作：把最关键的未完成句**留在未完成态**，作者绝不替读者解码

5. **对话碎片化**：工人/普通人不会说完整推理链。
   - `6句逻辑严整的反驳` → `2个断续的质问`
   - `200字演讲` → `3个追问`
   - `苏格拉底式格言对答` → `一个反问`
   - 检验标准：大声朗读对话，如果听起来像辩论赛/哲学对话录，改

### 符号冰山化

符号（如发卡/锁/钥匙）从不说自己是什么：
- 首次出现不标注隐喻义（"锁形发卡"→"一枚发卡"，锁形由后面的人指出）
- 变形节点不解释（"一个中间态。一个过程。"→"一个她说不出名字的形状"）
- 结尾不盖章（"愿意相信它像"→"也许不是。"句号。留犹豫）

### 改造优先级速查

| 优先级 | 改造项 | 信号词 |
|--------|--------|--------|
| ★★★★★ | 论说段砍削 | "资本要增值""X决定一切" |
| ★★★★★ | 后记/结尾声明 | "这个故事没有结局""看见是前提" |
| ★★★★☆ | 核心认知转折的Tell | "她意识到/发现" |
| ★★★★☆ | 未完成句的解码 | 紧跟破折号/省略号的心理翻译 |
| ★★★☆☆ | 对话碎片化 | 连续3句以上逻辑完整的对话 |
| ★★★☆☆ | 比喻精简 | 同一道理出现≥2个不同比喻 |

### 成功标准

改造后的小说应该让读者**读完之后沉默**，而不是读完之后点头。沉默是冰山水下的部分；点头只是水面上的浪花。

## 多轮修改后的力量感收紧

当用户反馈"全文变啰嗦了""力量感不足""不够有力"时（通常发生在多轮修改后——每轮加内容，全文逐渐膨胀），按以下方法做一次系统压缩。

### 核心诊断

多轮修改的副作用：每次按审核建议"加东西"（加回收动作、加个人史、加申诉行动），文本逐轮膨胀。句子的骨架被新增的"的/了/但/而/也/就/还"等虚词撑松，叙述框架词（"她想起""她觉得自己""有一种""像是一种"）堆积。本质是：**信息还在，但句子的重量丢了。**

### 压缩清单（按优先级）

1. **砍虚词**：每句过一遍，能删就删——
   - 的/了/但/而/也/就/还/而已/反正/根本/也许
   - "也没什么"→""，"但也没"→"没"，"并不是"→"不是"
   - "他也知道"→"他清楚"，"但她还是"→"她还是"

2. **砍叙述框架**：人物念头/感受直出，不加引导——
   - "她想起妈说过的话" → "妈说过的话"（直接出现）
   - "她觉得自己是清醒的" → "觉得是清醒"或直接写清醒的行为
   - "有一种说不出的东西。不是愤怒。不是悲伤。是一种像站在一条河里" → "不是愤怒，不是悲伤。像站在河里"

3. **砍限定修饰**：删掉不增加信息的中介语——
   - "如果算，她什么时候下班" → "什么时候下班"
   - "跟在家做饭没什么两样，只不过灶台换成了" → "跟在家做饭没两样，灶台换成了"
   - "她最后一次看见他" → "她看见他"

4. **断长句**：一段说了3层意思→拆成3句。一句说了两个分句→砍分句或拆成两句。
   - 例："不是某个老板在房间里拍板说'裁掉阿玲'。是一套算法、一份报表、一个投资回报率的数字" → 检查是否还需要中间的解释段

5. **保画面**：压缩时唯一不准动的——已经有效的画面句（"影子比发卡大""不多。但有了。""吐不出，咽不下"）。画面句本身就有重量，压缩前先标出来，保护它们不被误砍。

### 验证标准

- 全文通读一遍，每段读完问：这句话还能再短吗？这个虚词删了意思变了吗（没变→删）
- 与压缩前字数对比，**通常可减15-25%** 而不丢信息
- 关键画面句数量不变，但间距缩小→节奏感恢复

### 与其他方法的区别

| 方法 | 砍什么 | 保留什么 |
|------|--------|----------|
| 冰山写法 | 理论转述、心理直述、比喻解释 | 画面、身体反应、未完成句 |
| **力量感收紧** | 虚词、叙述框架、限定修饰、拖长句 | 所有信息、画面句、对话内容 |

两者互补。冰山砍作者塞给读者的"解说"；收紧砍多轮修改长出来的"脂肪"。两者都服务于一个目标：**让句子打人。**

## 陷阱

- 不要把小说写成论文加对话——读者不是来听课的
- 不要让思想框架直接说话（"矛盾论告诉我们…"）——让角色在经历中自己走到那个认知
- 不要在结尾给胜利——给"看见"，给"在路上"，给"愿意相信"
### 力量感收紧专属陷阱
- 压缩不等于删信息。画面句（如"影子比发卡大""不多。但有了。"）不准动——它们是骨头，砍了结构会塌。只砍虚词和叙述框架
- 不要在压缩时顺手把口语改成书面语——"你也不会多少钱"比"你的价格很低"更对
### 冰山改造专属陷阱
- 不要从Tell极端跳到过度留白极端——如果砍到读者完全无法推出水下内容，那是删减不是省略。省略的东西必须是你知道的，读者能感觉到的

### 理论文章转小说专属陷阱（场景2专用）

1. **论点寄生对话**：理论文章的论点会本能地钻进角色嘴里。诊断方法——删掉所有对话后重新读，如果故事只剩骨架没有血肉，说明对话在替论点打工。修复：把论点改写为角色遭遇的具体处境
2. **敌人纸片化**：理论文章通常有明确的"敌人"（资本家/父权/私有制），转化时容易写成脸谱反派。修复：每个对立角色必须有**真实的困境和理由**——赵磊不是坏人，他是"我只是执行制度"的活体标本
3. **"觉醒即自由"更危险**：理论文章有明确的"正确答案"，写到结尾时角色极容易突然悟道。修复：结尾永远用**悬置**——角色看清了一层，但下一层更难。看见不是到达，是出发
4. **Tell词重灾区**：理论文章转小说时"意识到/发现/明白"会比正常创作多3-5倍，因为作者急于把论点灌给读者。必须逐个替换为身体反应或数字事实
5. **主角后半段被动**：理论文章的逻辑线通常是被分析对象，转成故事后主角容易变成"被碾压的案例"而非行动者。修复：每幕至少给主角一个**主动行动**（哪怕失败），否则"坚持"只是精神状态不是实践
6. **论点堆叠致节奏崩塌**：当论点>10条时，如果强行单篇写完，每幕被迫塞入3-4个论点，叙事沦为论点清单。修复：做Step 2c密度评估，该分部就分部——宁拆两部各有弧线，不写一篇两头塌
