# PDF → Markdown 后处理：清洗重复页眉页脚

## 背景

政府公文/法规/制度类 PDF 转 Markdown 时，每页都有重复的页眉页脚：
- 页码（`- 1 -`, `- 2 -`...）
- 发布单位（"中华人民共和国国家发展和改革委员会发布"）
- 规章标题（"中华人民共和国国家发展和改革委员会规章"）

这些内容在 PDF 里每页都有，转成 Markdown 后会污染知识库/RAG 检索。

## 清洗脚本

仓库自带的 `scripts/clean-pdf-markdown.py` 可自动去除上述重复内容。

## 使用方式

```bash
python scripts/clean-pdf-markdown.py 输入.md 输出.md
# 不指定输出则原地覆盖
python scripts/clean-pdf-markdown.py 输入.md
```

## 清洗逻辑

1. 匹配 `- \d+ -` 模式的页码行 → 删除
2. 匹配固定页脚文本列表 → 删除（可扩充在 `footer_texts` 中）
3. 匹配固定页眉文本列表 + 紧随其后的标题行 → 删除
4. 跳过表格分隔线残留（`--- | --- | ---`、`----------- | ------- |` 类）→ 删除
5. 合并连续空行（多空行合并为一个）

## 定制化

页眉页脚文本在脚本顶部的列表变量中配置：
```python
footer_texts = ['中华人民共和国国家发展和改革委员会发布']
header_texts = ['中华人民共和国国家发展和改革委员会规章']
title_texts  = ['供电营业规则']
```
换一个政府规章 PDF 时，改这三个列表即可。

## 进阶清洗：首部脏表格

有些 PDF 开头有"发布文号"表格（如"2024 年 2 月 5 日第 9 次委务会通过"），MarkItDown 转成了一大堆 `|` 管道符表格，不属于页眉页脚但同样污染知识库。

手动处理：找到正文真正开始的位置（如"第一章 总 则"），删除之前的所有行。`clean_v2.py` 脚本展示了这一模式。也可用脚本快速截取：

```bash
grep -n "第一章" 输入.md | head -1 | awk -F: '{print $1+0}'
# 假设返回 10，则：
tail -n +10 输入.md > 输出.md
```

## 高阶清洗：语义重构（知识库专用）

基础清洗去除了页眉页脚，但 MarkItDown 输出的 Markdown 仍有两个问题：

1. **硬断行**：每 20-30 字换一行（PDF 排版残留），知识库分段会把一句话切成两段
2. **表格管道残留**：如 `第六条         |         | 供电企业供电的额定频率为交流               |             |     | 50 赫兹。`
3. **条款间缺空行**：多条被粘在一个段落里

### 语义重构流程

```
输入（基础清洗后的 .md）
  → 去掉行内管道符 | 和多余空格
  → 按"章标题 / 第X条开头 / 续行"逻辑合并硬断行
  → 在段落内按"第X条"模式拆分（含"零"字：第一百零一条）
  → 段落间空行分隔
  → 输出（每条款一个段落）
```

### 清洗脚本

`scripts/semantic-reflow-md.py` — 运行方式：

```bash
python scripts/semantic-reflow-md.py 基础清洗后的.md 最终版.md
```

### 重构核心逻辑

```python
# 1. 清洗管道符
s = re.sub(r'\s*\|\s*', ' ', s)  # "第六条 | ... | 50 赫兹" → "第六条 ... 50 赫兹"
s = re.sub(r' {2,}', ' ', s)

# 2. 段落合并（只有章/条/空行是分段边界）
is_章 = lambda s: bool(re.match(r'^第[一二三四五六七八九十百]+章', s))
is_条 = lambda s: bool(re.match(r'^第[一二三四五六七八九十百零]+条', s))
# "零"必须包含——"第一百零一条"的"零"不在常用数字字符里

# 3. 段落内拆分：用正则在合并后的段落中查找"第X条"重新分割
parts = re.split(r'(?=第[一二三四五六七八九十百零]+条)', paragraph)
```

### 效果对比

| 指标 | 基础清洗后 | 语义重构后 |
|------|-----------|-----------|
| 行数 | 868 | **245** |
| 章节 | 10 | ✅ 10 个章节 |
| 独立条款 | 粘在一起 | ✅ **110+ 条** |
| 表格管道 | 部分残留 | ✅ 全清 |
| 硬断行 | 每行断在 20 字 | ✅ 每条款一个完整段落 |
| Dify 知识库适配 | 分段不准 | ✅ 按条款分段，检索精准 |

### 正则注意事项

- **"零"字易漏**：`第一百零一条` 的 "零" 不在 `[一二三四五六七八九十百]` 中。两个地方都要加：
  - `is_条()` 检测
  - 段落内 `re.split(r'(?=第...)', ...)` 拆分正则
- **章标题独立行**：章标题（第二章 供电方式）不含"条"，不会被错误拆分
- **子项行**：`（一）`、`1.` 等子项行只合并到上级条款中，不独立分行
